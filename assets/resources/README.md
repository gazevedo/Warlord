# Recursos naturais

Os nomes foram confirmados visualmente e permanecem estáveis para uso pelo
registro `NATURAL_RESOURCE_ASSETS` em `map-assets.js`.

- `bush_01.png`: arbusto com taboas e pedras;
- `crystal_01.png`: formação de cristais;
- `lake_small_01.png` e `lake_large_01.png`: lagos;
- `rocks_small_01.png` e `rocks_medium_01.png`: formações de pedras;
- `mountain_01.png` e `mountain_snow_01.png`: montanhas;
- `ruins_01.png`: ruína de pedra;
- `fallen_log_01.png`: tronco caído.
